# Themes

Place every kept finding in one of the YES themes, using the names exactly as written
in the scope. The first six are current YES work. The rest are areas the team is
interested in, and they came out of its September 2026 strategy session.

For each theme:

- Use the exact theme name.
- Score it on the criteria, which carry equal weight, and let the research gap mark
  say how open the theme's central question still is.
- Propose one posture: adopt, adapt, or watch.
- Name a marquee finding and list the members by their exact names.

Rules:

- The theme list is fixed. The code holds every theme to it.
- A new theme needs at least three strong findings that fit none of the listed themes,
  and there can be only one.
- The evidence level sets the highest posture a theme can carry. The code lowers any
  posture the evidence does not allow.
- The question behind every theme is which research questions remain open, not which
  projects have been run.
