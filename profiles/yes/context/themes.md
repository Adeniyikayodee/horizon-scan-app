# Themes

Place every program design in one of the ten YES themes, using the names exactly as
written in the scope. The first six are current YES work. The last four are areas the
team is interested in.

For each theme:

- Use the exact theme name.
- Score it on the six criteria.
- Propose one posture: adopt, adapt, or watch.
- Name a marquee design and list the member designs by their exact names.

Rules:

- The theme list is fixed. The code holds every theme to it.
- A new theme needs at least three strong designs that fit none of the ten, and there
  can be only one.
- The evidence level sets the highest posture a theme can carry. The code lowers any
  posture the evidence does not allow.
